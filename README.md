# Text to MindMap Generator

Веб-сервис для генерации интерактивных mindmap из структурированного текста.

## Возможности

- 🎨 **Rich Text Editor** - мощный редактор на базе Lexical от Facebook
- 🎯 **Drag & Drop** - перетаскивание строк для реорганизации контента
- 🌳 **Автоматическая иерархия** - поддержка заголовков (H1-H6), параграфов, списков
- 🔄 **Real-time синхронизация** - mindmap обновляется в реальном времени
- 🎨 **Цветовое кодирование** - каждый тип элемента имеет свой цвет
- 📱 **Адаптивный дизайн** - работает на десктопах и планшетах

## Установка и запуск

### Предварительные требования

- Node.js 18+
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Режим разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Продакшн сборка

```bash
npm run build
npm run preview
```

## Как использовать

1. **Используйте панель инструментов** для форматирования текста:
   - H1-H6 для создания заголовков разных уровней
   - Кнопки списков для создания маркированных и нумерованных списков
   - B, I, U для стилизации текста

2. **Создайте структуру**:
   ```
   # Главная тема (H1)
   ## Подтема 1 (H2)
   ### Детали (H3)
   - Пункт списка
   - Еще один пункт
     - Вложенный пункт
   ## Подтема 2 (H2)
   Обычный текст
   ```

3. **Наблюдайте** как mindmap автоматически строится справа

## Поддерживаемая иерархия

Приложение поддерживает следующую иерархию элементов:

- **H1** → **H2** → **H3** → **H4** → **H5** → **H6** → **P** → **UL/OL**
- Вложенные списки (любой глубины)
- Иерархия адаптируется к фактическому контенту (можно начать с H2 или с обычного текста)

## Технологии

- **React** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **Lexical** - rich text редактор от Facebook/Meta
- **ReactFlow** - визуализация графов и mindmap
- **CSS3** - стилизация с градиентами
