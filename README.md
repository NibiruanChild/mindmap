# Text to MindMap Generator (Vue + Editor.js)

Веб-сервис для генерации интерактивных mindmap из структурированного текста.

## Технологии

- **Vue 3** - современный прогрессивный фреймворк
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **Editor.js** - блочный редактор от CodeX Team
- **Vue Flow** - визуализация графов и mindmap
- **CSS3** - стилизация с градиентами

## Возможности

- 📝 **Блочный редактор Editor.js** - чистый и удобный интерфейс
- 🌳 **Автоматическая иерархия** - поддержка заголовков (H1-H6), параграфов, списков
- 🔄 **Real-time синхронизация** - mindmap обновляется в реальном времени
- 🎨 **Цветовое кодирование** - каждый тип элемента имеет свой цвет
- 📱 **Адаптивный дизайн** - работает на десктопах и планшетах

## Установка и запуск

### Предварительные требования

- Node.js 18+
- npm или yarn

### Установка зависимостей

\`\`\`bash
npm install
\`\`\`

### Режим разработки

\`\`\`bash
npm run dev
\`\`\`

Приложение будет доступно по адресу \`http://localhost:5173\`

### Продакшн сборка

\`\`\`bash
npm run build
npm run preview
\`\`\`

## Как использовать

1. **Используйте блочный редактор** для создания контента:
   - Нажмите \`+\` для добавления нового блока
   - Выберите тип блока: Heading, List или Paragraph
   - Используйте уровни заголовков (H1-H6) для создания иерархии

2. **Создайте структуру** вашей mindmap
3. **Наблюдайте** как mindmap автоматически строится справа

## Поддерживаемая иерархия

- **Header (H1-H6)** - заголовки разных уровней
- **Paragraph** - обычные текстовые блоки  
- **List** - маркированные и нумерованные списки
- Иерархия адаптируется к фактическому контенту
